Breath Counting

Susokukan

Concentration

How to

Count each exhale silently from one to ten, then start again at one. If a count is lost or the mind wanders past ten without noticing, simply return to one without frustration.

Benefits

  • Gives the analytical mind a light task to prevent drifting
  • A reliable way to notice exactly when attention has wandered
  • A traditional Zen entry practice before longer silent sitting

Practice

10-15 minutes; treat losing count as useful information about the mind's pace, not a failure.
